# Portal Lab

Мобильный лаунчер Minecraft для **Android** и **iOS**: сборки, модпаки, моды с **Modrinth** и **CurseForge** (одновременно), аккаунты **Microsoft** и **офлайн**, ИИ-помощник **Порталус**, перевод описаний через **Google Translate**, редактор управления для десктопного Minecraft и запуск через **PojavLauncher**. Одна кодовая база на Flutter, Material 3, 10 палитр, 16 акцентов, прозрачные поверхности.

## Возможности

- **Сборки (инстансы)** — любая версия Minecraft (релизы, снапшоты, beta/alpha) и загрузчики Vanilla, Fabric, Quilt, Forge, NeoForge. Значки сборок, память Java, аргументы JVM, заметки, дублирование, сортировка, размер на диске.
- **Каталог обеих платформ** — поиск по Modrinth и CurseForge одновременно (режим «Все платформы») или по отдельности, с фирменными значками источников. Моды, модпаки, ресурспаки, шейдеры и датапаки. Фильтры по версии и загрузчику, сортировки, бесконечная прокрутка, избранное, галереи проектов.
- **Установка в один тап** — совместимая версия подбирается автоматически; моды идут в `mods/`, ресурспаки в `resourcepacks/`, шейдеры в `shaderpacks/`, датапаки в `datapacks/`.
- **Включение/выключение модов** — тумблер у каждого мода: выключенный мод получает суффикс `.disabled` и не загружается игрой. Иконка, автор, версия и источник у каждого мода.
- **Обновления и версии** — проверка обновлений всех модов одной кнопкой, обновление всех сразу, смена версии отдельного мода, смена версии Minecraft/загрузчика у сборки.
- **Порталус (ИИ-помощник)** — чат на открытых моделях Pollinations, выбор модели, поиск в интернете, генерация картинок (flux, turbo и другие), анализ логов и ошибок, быстрые вопросы и полная инструкция по лаунчеру. Порталус вызывается прямо со страниц модов и сборок.
- **Перевод описаний** — кнопка «Перевести описание (Google Translate)» на странице мода: автоматический перевод на язык лаунчера с возвратом к оригиналу.
- **Запуск игры** — страница запуска: проверка сборки, аккаунт, память, пошаговая передача в PojavLauncher через экспорт `.mrpack`. Быстрый запуск последней сборки с главной.
- **Управление** — редактор кнопок десктопного Minecraft (бег, инвентарь, чат, приседание, ESC, курсор, прыжок, выброс, F3, смена вида, Tab): перетаскивание, размер, прозрачность, пресеты «Классика / PvP / Строитель» и экспорт раскладки в формате PojavLauncher.
- **Аккаунты** — Microsoft (OAuth device flow, публичный Client ID Prism Launcher, Xbox Live → XSTS → Minecraft Services) в отдельном окне входа с кодом и шагами, офлайн-аккаунты, скины, обновление токенов.
- **Загрузки** — очередь с прогрессом, параллельность, общий индикатор.
- **Оформление** — светлая/тёмная/чёрная (AMOLED) темы, 10 палитр, 16 акцентов, прозрачные поверхности, RU/EN.

## Сборки

CI собирает приложение при каждом пуше (вкладка **Actions**):

- **Android** — подписанный APK (artifact `PortalLab-Android`)
- **iOS** — unsigned `.app` в zip (artifact `PortalLab-iOS`), для установки нужен свой Apple ID / подпись

Локально:

```bash
flutter create --platforms=android,ios --org dev.portallab --project-name portal_lab .
flutter pub get
flutter run
```

## Запуск игры

- **Android**: Java-версия Minecraft запускается через [PojavLauncher](https://play.google.com/store/apps/details?id=net.kdt.pojavlaunch) — на странице запуска экспортируйте сборку в `.mrpack` и импортируйте в Pojav. Раскладку управления можно собрать в Portal Lab и экспортировать в редактор Pojav.
- **iOS**: запуск Java-версии технически невозможен из-за ограничений платформы — Portal Lab используется как менеджер сборок и модов.

## Лицензии и ключи

- Код — GPL-3.0.
- Microsoft OAuth Client ID — публичный ID из открытых исходников [Prism Launcher](https://github.com/PrismLauncher/PrismLauncher) (device flow).
- CurseForge API-ключ — публичный ключ из открытых исходников Prism Launcher (условия CurseForge 3rd Party API).
- Modrinth API используется согласно правилам [modrinth.com](https://modrinth.com).
- Порталус работает через открытые модели [Pollinations](https://pollinations.ai); перевод — публичный эндпоинт Google Translate с фолбэками.
